# Cloud-Computing-Proyectos-Educacionales

Repositorio académico con las actividades y proyectos educacionales desarrollados en la asignatura de **Introducción al Cloud Computing**. 
Reúne ejercicios prácticos y análisis teóricos, desde los fundamentos de la infraestructura en la nube hasta el despliegue de servidores virtuales y contenedores.
El material está organizado por control complementario para facilitar su revisión.

## Estructura del repositorio

## Herramientas

- **AWS Academy:** cuenta de laboratorio para trabajar con servicios de AWS.
- **Amazon EC2:** creación y administración de servidores virtuales.
- **Docker:** creación y ejecución de contenedores.
- **nginx:** servidor web ejecutado dentro de un contenedor.
- **MobaXterm:** conexión SSH a las instancias.
